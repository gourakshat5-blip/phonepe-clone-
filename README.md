# PhonePe Clone 💜

A PhonePe-inspired payment dashboard built using HTML, CSS and JavaScript.

## 🚀 Features

- Responsive payment dashboard
- Balance display and hide/show balance
- Add Money functionality
- Send Money demo functionality
- Quick payment actions
- Recharge & Bill Payment section
- Recent Transactions
- Search input
- Notification interaction
- Toast notifications
- Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Design

## 📌 Note

This is a frontend demo project created for learning and practice.
It does not process real payments or connect to real banking/UPI services.
